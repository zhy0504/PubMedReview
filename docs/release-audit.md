## 生成隔离发布目录

在项目根目录运行 `python tools/prepare_release.py release/source-candidate`。目标目录必须尚不存在；不会覆盖之前的候选。工具会检查Python语法、与本地.env中的密钥值比对，并生成文件哈希清单。这不是完整的专业秘密扫描，发布前仍需检查配置和提示词是否包含个人信息。
