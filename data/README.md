# 内置期刊数据

直接来源：[hitfyd/ShowJCR](https://github.com/hitfyd/ShowJCR)，[原始 CSV 目录](https://github.com/hitfyd/ShowJCR/tree/master/中科院分区表及JCR原始数据文件)。收录日期：2026-09-09；沿用本地已使用快照，未重新下载或修改数据，不声称与当前上游版本完全一致。

- `FQBJCR2025-UTF8.csv`：中科院2025大类分区，使用 `大类分区` 和 `ISSN/EISSN`。
- `JCR2025-UTF8.csv`：JCR2025影响因子与分区，使用 `IF(2025)`、`IF Quartile(2025)_1`、`ISSN` 和 `EISSN`。
- `XR2026-UTF8.csv`：新锐2026大类分区，使用 `大类新锐分区`、`ISSN` 和 `EISSN`。

上游注明中科院数据来自 https://advanced.fenqubiao.com/ ，新锐数据来自 https://www.xr-scholar.com/ 。程序仅检查文件存在，不自动更新。
